# Legacy source migration

The original source directory is retained read-only by the author. This isolated directory copies necessary Python/configuration sources only. No source data, weights, prediction arrays, meshes or historical result directory was copied. Original and current small-file hashes are recorded in `ORIGINAL_SOURCE_MAP.json`; no commit identity is invented.

Preserved functional closure:

```text
main.py -> config_loader.py
        -> trainer.py -> dataset.py
                      -> model.py
                      -> model_factory.py -> model.py
                      -> output_result.py
                      -> showresult.py
        -> comparisons/run_benchmark.py -> comparisons/models/unet.py
        -> comparisons/run_ablation.py -> explicit child training commands
```

The model classes and historical numerical loss/metric implementations are not replaced with the revised paper's algorithms. The model files, generic result writer, historical interpolation models and original constraint-check helper retain their source bytes. I/O and interface corrections are:

- Read the selected/default YAML first, then apply CLI overrides; fail on missing/nonmapping configuration. Remove the machine-specific checkpoint and default real-mesh filename. Help works before optional dependencies are imported.
- Import training/visualization lazily at the main entry point. Report the missing original robustness implementation as unsupported.
- Require external input/checkpoint/output paths after YAML resolution. Keep all output/cache under the caller's external run, and prevent saved checkpoint I/O fields from overriding those paths.
- Honor an explicit single mesh file; preserve a consistent five-value worker return on read failure.
- Bind cache namespaces to source content and voxel shape. Rebuild only expected files in a matching owned namespace; input data and unrelated files remain untouched.
- Require explicit, matching architecture/state in the legacy benchmark. Preserve the original metric definitions and mark its outputs as historical, separate from revision evidence.
- Forward an explicit single-file selection to the benchmark as well as the trainer. Save benchmark failures and successful-evaluation counts in `benchmark_execution.json`; fail if no evaluation succeeds. U-Net training likewise records failed batches, averages only successful batches and refuses to label an empty or all-failed epoch as a best model.
- Have the ablation launcher write each arm directly, record its commands and refuse existing arm directories. Remove result-folder guessing, recursive deletion and moving of unrelated recent outputs.
- Retain generic PLY/report/GIF export. Require external paths for the standalone spin and ablation-summary commands. Add declared TensorBoard/Pillow dependencies required by the retained functionality.
- Create the requested external ablation-plot directory before saving its PNG and scalar summary.

Not migrated: `plot_comparison.py`, `plot_dataset_overview.py` and the old README. Their obsolete paper figures, hidden U-Net training, missing quantitative-evaluation dependency and unverified source/physics claims are not part of the accurate revised public workflow.

Verification scope: standard-library/PyYAML tests, source import-closure inspection and a fake checkpoint loader. No private mesh, real weight, GPU update or scientific result was accessed or generated by this migration.

Additional execution verification: a newly created toy cube mesh was used for one tiny CPU epoch and a separate trusted-checkpoint warm start. Both exited successfully and the toy input was unchanged. An initial warm-start logger ordering failure was preserved, corrected and rerun. Final visualization path routing was checked with a renderer fixture. These checks establish software functionality only; they do not reproduce historical scores or test the full GPU training/export workload. New layout checks and their scope are recorded in the outer `VERIFICATION.json`.

Final interface review added mechanical fixtures for exact benchmark file selection, total/partial benchmark failures, empty/all-failed/partial U-Net epochs and zero-epoch rejection. A scalar-only temporary two-row CSV also exercised actual ablation PNG/CSV output into a new directory. The combined legacy interface suite passed 20 tests and 2 subtests. These are software checks; fake tensors/checkpoints never represent scientific evaluation.
